# Onlab Studio releases

The desktop app of [Onlab Studio](https://onlabstudio.com), for Windows and Linux. The Mac app joins once it is signed.

This repository holds the app's files and nothing else: the installers, and the files the app reads to update itself. The source is not here.

- To install it: [onlabstudio.com/download](https://onlabstudio.com/download)
- Once installed, the app updates itself from the newest release here.
